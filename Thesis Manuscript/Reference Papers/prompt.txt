## My role
I do NOT edit the LaTeX files directly. I produce Claude Code
CLI prompts that the developer pastes into Claude Code, which
works in the LaTeX manuscript codebase. My job is to:
- Understand the manuscript structure
- Identify where content from the proposal (.tex) maps to
  the manuscript codebase
- Write precise Claude Code prompts for content transfer
  and LaTeX formatting tasks
---
## What I need from Claude Code
Claude Code serves as a LaTeX assistant. It:
- Reads the existing manuscript codebase structure
- Transfers content from Rodriguez-SP-Proposal.tex to
  the appropriate manuscript files
- Handles LaTeX formatting, sectioning, and compilation
- Does NOT write new content — transfers and reformats
  existing content only
- Does NOT provide writing assistance — structure and
  formatting only
